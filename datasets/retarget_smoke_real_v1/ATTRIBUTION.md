# `retarget_smoke_real_v1` attribution and rights boundary

The 12 image files are materialized only into the Git-ignored
`local_data/retarget_smoke_real_v1/images/` directory. The pinned URLs, official File
pages, license names, access date, SHA-256 values, authors, required attribution, scene
category and redistribution status are recorded in `source_manifest.csv`.

The two Public Domain sources are the 1940 *Meng Lijun* poster and Mohylek's wristwatch
photograph. The remaining sources require the
attribution text in the manifest, a link to the recorded CC license, and a statement
that retargeted outputs are modifications. CC BY-SA outputs that are redistributed must
use the same or a compatible license.

CC licensing covers the photographers' copyright. It does not independently grant
personality, trademark, advertising-artwork, endorsement, or identity-inference rights.
The sources and generated Run are therefore restricted to local algorithm Smoke, with
no marketing use, identity inference, public upload, or implied endorsement. Publishing
any source, thumbnail, candidate, or Run requires a separate release-context review.

The selection rationale and official-source research are in
`docs/research/real-smoke-source-research.md`.
